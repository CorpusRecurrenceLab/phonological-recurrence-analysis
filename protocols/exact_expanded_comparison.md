# Exact and expanded twelve-work comparison

This is an exploratory restricted-expanded counterpart to the exact analysis, not a preregistered confirmatory test. The corpus set, direct consonant substitutions, block geometry, radii, and fixed permutations are applied symmetrically to both modes.

## Matching modes

- **Exact:** identical mixed triplets.
- **Expanded:** identity or exactly one direct consonant substitution from the fixed set in `transcription.md`.

Expanded matching permits no vowel change, reversal, transitive closure, or multiple substitution. In the distance metric, a maximum-cardinality one-to-one matching prevents any motif type from being counted more than once.

## Coverage and density

Coverage uses block lengths 512/1,280, offsets 0/half, and radii 32/64/128. Figure 2 displays the 512-unit, zero-offset, radius-64 exact density on actual resolved-stream coordinates. Excluded intervals are shown as missing material, not as zero coverage.

## Distance

The distance grid uses the geometry defined in `analysis.md`, with maximum gaps 256/1,024/4,096. Figure 1 uses cap 1,024, offset 0, phase 0; Table 2 averages all four offset/phase conditions at cap 1,024.

## Rearrangement

The spatial control is defined in `spatial_control.md`. Exact and expanded modes use the identical fragments, permutations, and retained material.

## Reporting rule

All fixed settings and counterexamples are retained. Parameters are not selected to recover a preferred corpus ranking. The comparison is not calibrated as a poetry scale.
